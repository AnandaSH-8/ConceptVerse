# ConceptVerse

ConceptVerse is an interactive educational platform for learning software engineering concepts through premium 3D visual explanations.

## Features

- Dark modern learning dashboard
- Responsive chapter navigation and progress UI
- Animated 3D request-flow scene built with React Three Fiber
- Premium motion and glassmorphism-inspired design system

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```
